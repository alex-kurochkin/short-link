# Сокращатель ссылок на Laravel 12

Веб-приложение для создания коротких ссылок с отслеживанием статистики переходов.

## Возможности

- Регистрация и аутентификация пользователей
- Создание коротких ссылок (6-символьный код)
- Редирект с отслеживанием переходов
- Статистика: IP адрес, дата/время перехода
- Личный кабинет на Filament v3
- Просмотр списка своих ссылок
- Удаление ссылок
- Детальная статистика по каждой ссылке

## Настройка длины кода
- SHORT_LINK_CODE_LENGTH в config/short-links.php и .env

## Требования

- PHP 8.4+
- Composer
- SQLite (или другая СУБД)
- Filamentphp v3

## Установка

### Запустите скрипт установки

```bash
chmod +x install.sh
./install.sh
```
* Если в системе отсутствуют необходимые компоненты (модули PHP и менеджер пакетов Composer) - раскомментируйте строки в начале файла install.sh.
* Учтите, что для этого потребуются права суперпользователя (root). Также данные команды предполагают, что операционная система основана на Debian.

## Запуск

```bash
php artisan serve
```
